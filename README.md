# سامانه مدیریت حضور و غیاب سرمد (SARMAD Attendance)

سامانه جامع، چندمستأجره (Multi-Tenant) و مدرن ثبت و پردازش حضور و غیاب پرسنل با استفاده از وب‌کم، تشخیص چهره محلی، صف آفلاین در زمان قطعی اینترنت، محاسبه شیفت و کسر کار/اضافه‌کار، خروجی اکسل، محاسبه حقوق و دستمزد، و اعلان‌های تلگرام.

این سامانه به صورت اختصاصی برای استقرار سبک و پایدار روی **هاست‌های لینوکسی اشتراکی (DirectAdmin / cPanel)** با پشته **PHP 8.1+** و دیتابیس **MySQL / MariaDB** توسعه یافته است و هیچ وابستگی اجرایی به سرورهای سنگین Node.js یا ابزارهای خارجی ندارد.

---

## ۱. ویژگی‌ها و قابلیت‌های کلیدی

1. **چندمستأجره (Multi-Tenant):**
   - تفکیک کامل داده‌های هر کسب‌وکار/کلینیک در سطح کدهای بک‌اند (Tenant Isolation).
   - دیتابیس مشترک با پروژه‌های دیگر؛ ایزولاسیون کامل جداول با پیشوند اختصاصی **`attendance_`**. هیچ جدول خارجی (مانند `barber_*`، `clinic_*` و ...) لمس نمی‌شود.
2. **پنل مدیریت کل (مالک / Owner):**
   - مدیریت مشتریان (کسب‌وکارها) و اشتراک‌ها.
   - فعال/غیرفعال‌سازی ماژول‌ها و فیچر فلگ‌ها برای هر کسب‌وکار.
   - دسترسی ورود اضطراری با ثبت دقیق ردپا (Audit Trail).
   - مانیتورینگ دستگاه‌ها و گزارش لاگ‌های سیستم.
3. **پنل مدیر کسب‌وکار (کارفرما / Manager):**
   - داشبورد آماری آنلاین و وضعیت پرسنل (حاضران، غایبان، تأخیرها).
   - تعریف شعبه‌ها، پرسنل، شیفت‌های کاری چرخشی و انعطاف‌پذیر با فرجه‌های مجاز ورود و خروج.
   - مدیریت مرخصی‌ها، تعطیلات و اصلاحات دستی تردد با ذکر دلیل و ردیابی حسابرسی.
   - ثبت ۳ نمونه چهره برای هر پرسنل با بررسی زاویه، وضوح و نور.
   - گزارش‌گیری پیشرفته با فیلترهای تاریخی شمسی (روزانه، ماهانه، فردی، تأخیر، اضافه‌کار، غیبت).
   - خروجی استاندارد فایل اکسل (`.xlsx`) با طراحی راست‌به‌چپ و فرمول‌بندی شده.
   - ماژول حقوق و دستمزد با امکان پیش‌نمایش، فریز دوره و اصلاح حقوق.
   - ماژول ربات تلگرام برای ارسال اعلان‌های آنی ورود/خروج و گزارش روزانه (با رمزنگاری توکن).
4. **دستگاه کیوسک / PWA (ثبت تردد با تبلت یا موبایل):**
   - تبدیل هر دستگاه تبلت، موبایل یا لپ‌تاپ به دستگاه حضور و غیاب ثابت بدون لاگین پرسنل.
   - فعال‌سازی امن دستگاه با کد یک‌بارمصرف و توکن رمزنگاری‌شده (Bearer Token).
   - رابط کاربری تمام‌صفحه تیره، واکنش‌گرا و لمسی.
   - **تشخیص چهره محلی (On-Device):** پردازش هوش مصنوعی با کتابخانه محلی `face-api.js` و `tfjs` در مرورگر بدون ارسال تصویر خام به سرور.
   - **عدم استفاده از Liveness:** طبق قوانین و طراحی سیستم، تشخیص زنده‌بودن (Liveness Detection) وجود ندارد.
   - **کارکرد آفلاین (PWA + Service Worker):** ثبت تردد در صورت قطع شبکه و همگام‌سازی (Batch Sync) خودکار پس از اتصال مجدد.

## ۲. پیش‌نیازها و فناوری‌ها

- **زبان بک‌اند:** PHP نسخه 8.1 یا بالاتر (تست‌شده تا 8.4).
- **پایگاه داده:** MySQL نسخه 5.7+ یا MariaDB نسخه 10.3+.
- **اکستنشن‌های موردنیاز PHP:**
  `pdo`, `pdo_mysql`, `mbstring`, `openssl`, `curl`, `gd`, `zip`, `xml`, `fileinfo`
- **وب‌سرور:** Apache با فعال بودن `mod_rewrite` و پشتیبانی از فایل‌های `.htaccess`.
- **بدون وابستگی به Composer یا Node.js در سرور هاست:**
  تمام کتابخانه‌های لازم (مانند `PhpSpreadsheet` برای تولید اکسل و مدل‌های تشخیص چهره هوش مصنوعی) به صورت محلی در سورس پروژه وندور شده‌اند.

## ۳. ساختار پوشه‌ها و فایل‌های مهم

```text
├── app/                  # کدهای اصلی بک‌اند طبق معماری MVC
│   ├── Api/              # کنترلرها و میان‌افزارهای API دستگاه و مدیر
│   ├── Controllers/      # کنترلرهای وب پنل مالک و پنل مدیر
│   ├── Core/             # کلاس‌های پایه (Database, Router, Security, Session, Config)
│   ├── Middleware/       # میان‌افزارهای احراز هویت، CSRF، نقش و مستأجر
│   ├── Models/           # مدل‌های ارتباط با دیتابیس (ActiveRecord سبک)
│   ├── Services/         # منطق تجاری (حسابگر شیفت، موتور حضور و غیاب، حقوق، تلگرام)
│   └── Support/          # توابع کمکی تقویم جلالی، ورودی‌ها و آدرس‌ها
├── assets/               # فایل‌های استاتیک فرانت‌اند
│   ├── css/              # استایل‌های تم تیره و مدرن پنل‌ها و کیوسک
│   ├── js/               # کدهای جاوااسکریپت، صف آفلاین و PWA
│   ├── models/           # وزن‌های مدل‌های محلی هوش مصنوعی (face-api 1.0.0)
│   └── vendor/           # نسخه‌های محلی tfjs 1.7.4 و face-api.js
├── config/               # تنظیمات سامانه
│   ├── config.sample.php # نمونه کانفیگ برای راه‌اندازی
│   └── config.php        # کانفیگ فعال و مشخصات دیتابیس (روی هاست ساخته می‌شود)
├── install/              # نصب‌کننده تحت وب و فرم راه‌اندازی اولیه
├── routes/               # تعریف مسیرهای وب و API (web.php, api.php)
├── sql/                  # اسکریپت‌های DDL ساخت جدول‌ها و ارتقاهای نسخه
├── storage/              # لاگ‌ها، کش، سشن‌ها و قفل نصب (installed.lock)
├── tools/                # ابزارهای خط فرمان و اسکریپت‌های تست مستقل
│   ├── db_check.php      # ابزار پزشک و عیب‌یابی ارتباط با دیتابیس
│   ├── test_connection.php # تست مستقل ۹ بندی PDO
│   └── migrate.php       # مایگریشن دیتابیس از خط فرمان
├── views/                # قالب‌های HTML فرانت‌اند (RTL، واکنش‌گرا و ماژولار)
├── .htaccess             # روتینگ امنیتی و هدایت فرانت کنترلر آپاچی
├── index.php             # فایل ورودی اصلی سامانه
└── README.md             # راهنمای جامع پروژه
```

## ۴. راه‌اندازی و اجرای محلی (برای توسعه‌دهنده)

اگر می‌خواهید پروژه را روی سیستم خودتان اجرا کنید:

۱. **اجرای سرور داخلی PHP:**
   کافیست در پوشه ریشه پروژه دستور زیر را بزنید:
   ```bash
   php -S 0.0.0.0:8080 tests/router.php
   ```
۲. **باز کردن در مرورگر:**
   - اگر اولین بار است: `http://localhost:8080/install/` را باز کنید تا ویزارد نصب اجرا شود.
   - صفحه ورود: `http://localhost:8080/login`

## ۵. اجرای تست‌های خودکار

پروژه دارای سوئیت تست‌های جامع است که بدون فیک/شبیه‌سازی و روی دیتابیس واقعی اجرا می‌شوند:

```bash
# تست‌های امنیتی و ضد نشت داده‌ها (69 تست)
php tests/security_tests.php

# تست‌های موتور محاسبه شیفت و تردد (151 تست)
php tests/engine_tests.php

# تست‌های جامع گزارشات، اکسل، حقوق و تلگرام (240 تست)
php tests/stage7_tests.php

# تست اندپوینت‌های HTTP مرحله ۷ (111 تست)
bash tests/stage7_http.sh http://localhost:8080

# تست صف و ثبت آفلاین دستگاه کیوسک (80 تست)
node tests/device_queue_test.js http://localhost:8080

# تست جابجایی ساب‌دامین و تغییر پوشه (30 تست)
bash tests/move_folder_check.sh http://localhost:8080 http://localhost:8080
```

## ۶. نحوه استقرار (Deploy) روی دایرکت‌ادمین / هاست واقعی

۰. ساخت بستهٔ انتشار از ریشهٔ مخزن: `./build.sh` (بستهٔ امن، بدون کانفیگ) یا برای استقرار آمادهٔ دایرکت‌ادمین `./build.sh --with-config` (بستهٔ **محرمانه** شامل `config/config.php` آماده؛ خروجی در `release/` و خارج از گیت). هر دو بسته طوری ساخته می‌شوند که با Extract مستقیم در `public_html` هیچ پوشهٔ اضافه‌ای نسازند.
۱. فایل سورس یا زیپ انتشار را در پوشه مورد نظر روی هاست (مثلاً `domains/example.com/public_html/`) اکسترکت کنید.
۲. در DirectAdmin به بخش **MySQL Management** بروید و یک دیتابیس و کاربر بسازید و دسترسی کامل به آن دیتابیس را به کاربر بدهید.
۳. آدرس سایت را در مرورگر باز کنید (سامانه خودبه‌خود شما را به صفحه `/install/` هدایت می‌کند).
۴. اگر بستهٔ `--with-config` را استخراج کرده‌اید، نصب‌کننده پیکربندی آماده را شناسایی می‌کند: کافی است «تأیید و ادامه نصب با همین پیکربندی» را بزنید (رمز دیتابیس دوباره پرسیده نمی‌شود). در غیر این صورت اطلاعات دیتابیس را دستی بررسی کنید و دکمه اتصال را بزنید. تست اتصال دولایه است (اول سرور، بعد همان دیتابیس) تا در صورت وصل‌نبودن کاربر به دیتابیس در دایرکت‌ادمین، پیام دقیق بدهد.
۵. در مرحله بعد مشخصات مالک و اولین کسب‌وکار را تعیین کنید.
۶. سامانه ۴۱ جدول با پیشوند `attendance_` ساخته و بلافاصله با ایجاد فایل `storage/installed.lock` نصب‌کننده را برای همیشه قفل می‌کند.

---

## ۷. نکات امنیتی مهم

- فایل `config/config.php` حاوی رمز دیتابیس و کلید رمزنگاری اپلیکیشن است؛ هرگز آن را در گیت‌هاب عمومی قرار ندهید.
- در دیتابیس مشترک، دسترسی کدها توسط گارد امنیتی `SqlGuard` محدود شده و هیچ عملیاتی خارج از جداول `attendance_*` مجاز نیست.
- توکن‌های دستگاه‌ها و ربات تلگرام با الگوریتم رمزنگاری AES-256 در دیتابیس نگهداری می‌شوند.
