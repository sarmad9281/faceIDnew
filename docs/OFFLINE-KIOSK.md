# کیوسک آفلاین

برای آماده‌سازی هر مرورگر/دستگاه، پس از استقرار نسخه جدید یک‌بار `/device` را با اینترنت و HTTPS باز یا رفرش کنید. دستگاه باید فعال باشد، تنظیمات و گالری چهره پرسنل از سرور دریافت شوند و نصب Service Worker و دانلود فایل‌های مدل کامل شده باشد. نصب برنامه به صفحه اصلی جایگزین این آماده‌سازی نیست. قطع اینترنت پیش از تکمیل آن، پاک‌کردن داده‌های مرورگر یا حذف خودکار cache/IndexedDB توسط مرورگر می‌تواند کارکرد آفلاین را ناممکن کند. مدل‌های سفارشی خارج از مسیر پیش‌فرض نیز باید قبلاً در همان مرورگر بارگذاری و کش شده باشند.

پس از آماده‌سازی، بازکردن یا رفرش کیوسک در قطعی شبکه از پوسته کش‌شده، آخرین تنظیمات دستگاه و گالری محلی استفاده می‌کند. برای تشخیص، اجازه دوربین و چهره ثبت‌شده و هم‌گام‌شده لازم است. تردد موفق ابتدا در صف محلی قرار می‌گیرد، نه در پایگاه داده سرور؛ پس از بازگشت ارتباط، سرور آن را بررسی می‌کند و ممکن است رد کند. موارد ردشده در صف می‌مانند. اگر حافظه محلی در دسترس نباشد یا صف پر باشد، دستگاه خطا می‌دهد و موفقیت ساختگی اعلام نمی‌کند.

تنظیمات و اعتبار دستگاه در localStorage و داده زیست‌سنجی گالری در IndexedDB همان مرورگر نگهداری می‌شوند؛ APIها در Service Worker کش نمی‌شوند. هنگام قطعی شبکه، لغو یا تغییر وضعیت دستگاه/پرسنل در سرور تا برقراری مجدد ارتباط قابل اطلاع به دستگاه نیست. دستگاه را فقط در محیط مورد اعتماد استفاده کنید.

## تست رگرسیون محلی

با Node.js نسخه ۲۰ یا بالاتر:

```sh
npm ci --prefix tests
npm run --prefix tests offline
```

این تست‌ها Service Worker را در VM و کنترلر واقعی مرورگر را با DOM، IndexedDB، API و موتور چهره شبیه‌سازی‌شده بررسی می‌کنند؛ جایگزین آزمایش دوربین، مدل واقعی و هم‌گام‌سازی با سرور و پایگاه داده در staging نیستند.
